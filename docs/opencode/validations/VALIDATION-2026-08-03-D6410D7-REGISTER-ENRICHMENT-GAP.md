\#\# 5\. Независимо подтверждённые причины в коде

\#\#\# 5.1. services/protocol\_register\_extractor.py

Схема extraction-pass неполная:

\- questions не содержат responsible/deadline;  
\- risks не содержат response strategy/responsible;  
\- tasks не содержат expected\_result/status.

Extractor получает только первые 8000 символов расшифровки и первые 4000 символов тематических блоков.

Это создаёт прямой риск потери второй половины встречи.

\#\#\# 5.2. services/processing\_service.py

При переносе результата extractor:

\- у questions не копируются responsible/deadline;  
\- у risks не копируются measures/responsible;  
\- у tasks не копируются expected\_result/status.

Поля теряются даже при наличии в исходном ответе модели.

\#\#\# 5.3. protocol\_templates/project\_detailed.py

Рендер решений явно сокращён до двух колонок.

Для рисков задан общий fallback:

«Стратегия не определена; требуется отдельная проработка».

Для вопросов общий fallback ответственного:

«Требуется назначить».

Для задач общий fallback ожидаемого результата:

«Не указан».
