# Валидации

Независимые повторные проверки после каждого цикла исправлений.

## Формат имени

```
VALIDATION-YYYY-MM-DD-<sha>.md
```

`<sha>` — первые 7 символов базового коммита аудита.

## Содержание

Каждый файл валидации содержит:

1. Результаты автоматических проверок (`compileall`, `pytest`, `ruff`, `mypy`).
2. Постатейную проверку каждого замечания из аудита.
3. Статус каждого замечания: `FIXED`, `PARTIALLY_FIXED`, `NOT_FIXED`, `NOT_VERIFIABLE`, `REGRESSION`.
4. Итоговое заключение: `accepted` или `changes_required`.

## Правила

- Валидацию выполняет **независимый проверяющий** (человек или отдельный экземпляр OpenCode).
- OpenCode, выполнявший исправления, **не имеет права** проводить валидацию собственных изменений.
- Статус `accepted` означает, что все замечания устранены и можно выполнять merge PR.
