\#\# 3\. Подтверждённые дефекты

\#\#\# 3.1. Название сформировано из цели

Сейчас title начинается как:

\`\`\`  
Протокол внутренней встречи от 31.07.2026. Цель встречи — обследовать и согласовать целевую схему работы...  
\`\`\`

Цель встречи — отдельное поле раздела 3\. Она не должна использоваться как тема документа.

Целевой заголовок контрольной страницы:

\`\`\`  
Протокол от 31.07.26. УралДронЗавод \+ Первый БИТ — демонстрация процессов блока «Производство»  
\`\`\`

Допустима только типографская нормализация: \`ПервыйБИТ\` → \`Первый БИТ\`, дефис → тире, прямые кавычки → «ёлочки».

\#\#\# 3.2. Заголовок продублирован

\#\# 4\. Подтверждённые причины в коде

\#\#\# \`services/protocol\_title.py\`

\`extract\_short\_topic()\` ставит \`meeting\_purpose\` выше \`protocol\_title\` и темы блоков. Поэтому полная цель попадает в title.

\#\#\# \`detect\_meeting\_type()\`

Пустой или неопределённый client\_name автоматически означает \`internal\`. Нужны три состояния:

\`\`\`  
external  
internal  
unresolved  
\`\`\`

\#\#\# \`resources/project\_profiles.json\`

Сейчас есть только профиль Роял Фуд. Профиль УралДронЗавода отсутствует.

\#\#\# \`services/project\_context\_resolver.py\`

\`\_resolve\_with\_llm()\` не получает текст расшифровки, имя файла, title, участников и процессы. В LLM уходит только общая команда «Определи проект по контексту встречи».

\#\#\# \`protocol\_templates/project\_standard.py\`

Storage body содержит \`\<h1\>{title}\</h1\>\`, хотя page title уже передаётся Confluence отдельно.

\#\#\# \`services/standard\_protocol\_llm\_compressor.py\`

Prompt требует «абзацы и пункты» без критерия, когда список допустим. Ответ LLM с bullets принимается без проверки семантики.

\#\# 16\. Нормализация ячейки

Создать \`normalize\_cell\_structure(cell, source\_text)\`.

Правила:

1\. Первый paragraph \+ остальные bullets без list\_intro → все fragments в paragraphs.  
2\. Последовательные предложения об этапах процесса → paragraphs.  
3\. Список из одного элемента → paragraph.  
4\. Неоднородный список → paragraphs.  
5\. Явная вводная фраза \+ однородные элементы → сохранить list.  
6\. Не терять числа, даты, системы, роли и документы.

\`\_render\_cell()\` должен использовать нормализованный \`structure\_type\`.
