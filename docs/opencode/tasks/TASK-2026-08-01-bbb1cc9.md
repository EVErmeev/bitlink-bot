\`\`\`text

→ llm.generate\_json(...)

→ template.assemble\_from\_llm\_json(...)

\`\`\`

Добавить в base template:

\`\`\`python

    self,

    ...  
\`\`\`

Каждый из четырёх шаблонов должен преобразовывать собственный schema-valid dict в Protocol.

\- основной pipeline не использует строковый \`assemble\_with\_llm\_output()\`;  
\- при невалидном JSON после retries элемент получает \`failed\` и не публикуется;  
\- mock LLM возвращает schema-valid fixture для каждого template ID;  
\- реально сохраняются \`llm\_request.json\`, \`llm\_response\_raw.txt\`, \`llm\_response\_parsed.json\`, \`llm\_schema\_validation.json\`.

\#\# 11\. Переписать ложноположительные тесты

Не допускаются:

\- \`assert True\`;  
\- \`assert "success" in result\` без проверки значения;  
\- \`if file.exists(): assert ...\`;  
\- проверка конструктора вместо поведения;  
\- тест ошибки чтения вместо ошибки валидатора;  
\- тест «не публикует», который не вызывает publication path.

Каждый тест должен падать на старой дефектной реализации и проверять точный статус, вызовы зависимостей, созданные файлы и точную ошибку.
